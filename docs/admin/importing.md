# Importing content

Everything here changes only the draft, so you can review it, undo it, or save it.

## Content JSON

Download the draft or the saved file as a backup, or import a `portfolio.json` (for example from another copy of this project). The file is validated first and every problem is listed.

## Publications from BibTeX

Google Scholar, ORCID and reference managers export BibTeX. Paste it or choose a `.bib` file, tick the entries to add, choose the publications block and a starting logo. Titles, authors, venue, year and month, and a DOI or URL link are filled in. Entries already in the block (same title) are skipped.

## JSON Resume

Choose a [JSON Resume](https://jsonresume.org) file to fill in your name and summary, social links, work (into a timeline group), education (into a degrees block) and publications. Switch off any part you do not want.

## History

The **History** page lists the copies of `portfolio.json` kept before each save (the newest 30, in the git-ignored `.admin-history` folder). Compare one with the draft or load it into the editor.
