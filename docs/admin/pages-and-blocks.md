# Pages and blocks

A page is a path, a navigation label, a "show in navigation" switch and an ordered list of **blocks**. The first page is the home page. Routes and navigation are generated from the list.

## Adding pages

Open **Pages** and use **Add page**. Choose a template (Experience, Research, Talks, Writing, Links, Contact or Blank); each starts with the blocks that page usually needs and a free id and path. Paths `/`, `/admin` and `/splash` are reserved.

**Duplicate** on a page copies it with a new id and path (`/talks-copy`), so the copy is valid straight away.

## Working with blocks

- **Add block** opens a palette with a picture and description of every block type.
- The small **+** between two blocks inserts a new block at that position.
- Drag a block by its handle to move it, or use the arrow buttons.
- Each item shows its kind (PAGE, BLOCK, ENTRY, ...) and a coloured edge for its nesting level.

## Seeing your work

- Opening a block scrolls the preview to it.
- Turn on **Click to edit** in the preview, then click any block on the site to open its fields.
- Switch the preview between phone, tablet and desktop widths, and between the site's own, light and dark colours.

## Dates

Dates have a year, an optional month and an optional day. The end of a range can be **Present**, and can be marked as expected (shown as "(expected)"). A prefix such as "Filed" or "Issued" goes in front. The site shows dates in the language set under SEO.

## Text blocks

Text blocks use Markdown: `**bold**`, `*italic*`, `[a link](https://example.com)`, `- lists`, `## headings` and code. The editor has buttons for each and a preview.
