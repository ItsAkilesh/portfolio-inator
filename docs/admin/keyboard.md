# Keyboard shortcuts

| Keys                           | Action |
| ------------------------------ | ------ |
| Ctrl/Cmd+S                     | Save   |
| Ctrl/Cmd+Z                     | Undo   |
| Ctrl/Cmd+Shift+Z or Ctrl/Cmd+Y | Redo   |
| Ctrl/Cmd+K                     | Search |

- In search, use the arrow keys and Enter.
- In icon and image pickers, type to filter, use the arrow keys, Enter to choose and Escape to close.
- List items have move up and move down buttons, so everything that can be dragged can also be reordered from the keyboard.
- Escape closes dialogs.
